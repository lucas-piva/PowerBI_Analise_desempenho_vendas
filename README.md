# Dashboard de Análise de Vendas e Promoções

Projeto de Business Intelligence (BI) desenvolvido para análise de desempenho comercial e acompanhamento de campanhas promocionais.

O dashboard foi criado com o objetivo de transformar dados de vendas em insights estratégicos, permitindo monitorar resultados, identificar tendências, avaliar o impacto de promoções e apoiar a tomada de decisão do negócio.

A solução apresenta indicadores relevantes como faturamento, volume de vendas, desempenho por período, produtos com maior saída, impacto das promoções e métricas comparativas de performance.

## Tecnologias e Ferramentas

* Power BI
* DAX
* Power Query
* Modelagem de Dados
* ETL
* Visualização de Dados

## Funcionalidades do Dashboard

* Análise de desempenho de vendas
* Comparativo entre períodos
* Avaliação de campanhas promocionais
* Indicadores de faturamento e crescimento
* Visualização interativa de métricas comerciais

## Objetivos do Projeto

* Apoiar decisões estratégicas comerciais
* Identificar oportunidades de crescimento
* Monitorar resultados de promoções
* Facilitar a análise de indicadores de vendas
